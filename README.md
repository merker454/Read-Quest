# 📖 Read Quest

**Gamified Reading Tracker for All Ages**

Transform reading into an exciting adventure! Read Quest is a free, interactive web application that makes reading engaging for children and adults through gamification, personalized recommendations, and interactive quizzes.

## ✨ Features

### 📚 Multi-Level Reading System
- **4 Reading Levels:** Early Reader (K-5), Junior (Grades 6-9), Teen (Grades 9-12), Adult (17+)
- **40+ Curated Books** per level with real book recommendations
- **Personalized Recommendations** based on reading level and interests

### 🎮 Gamification
- **Points System:** Earn points for each chapter read
- **Reading Streaks:** Build consecutive reading days
- **Achievements & Badges:** Unlock rewards like 🏆 Trophies, ⭐ Stars, 💎 Gems
- **Custom Rewards:** Set personalized rewards for completing challenges

### 🏆 Challenges
- **Weekly Challenge:** Read 3 chapters for rewards
- **Monthly Challenge:** Earn points toward monthly goals
- **Streak Challenge:** Maintain a 30-day reading streak

### 📊 Progress Tracking
- **Reading Dashboard:** View total points, books read, current streak
- **Chapter Logging:** Track progress chapter-by-chapter
- **Statistics:** Visual progress bars for all challenges
- **Multi-Profile Support:** Create profiles for multiple readers

### 🤖 AI-Powered Quizzes
- **Interactive Quizzes:** Claude API generates smart questions based on book content
- **Multiple Question Types:** Multiple choice, true/false, short answer
- **Instant Feedback:** Get explanations for every answer
- **Accuracy Scoring:** See your comprehension percentage

### 🎨 Personalization
- **Custom Avatars:** Choose from 50+ emoji avatars
- **Profile Customization:** Personalize each reader's experience
- **Flexible Reading Goals:** Set rewards for any challenge

### 📱 Cross-Platform Access
- **Progressive Web App (PWA):** Install on iOS, Android, Windows, Mac
- **Offline Support:** Works without internet connection
- **Responsive Design:** Optimized for mobile, tablet, and desktop
- **Native App Feel:** Works like a real mobile app

## 🚀 Getting Started

### Option 1: Use Online (No Installation)
1. Visit **[Read Quest Live App](https://merker454.github.io/Read-Quest/app/)**
2. Start tracking your reading immediately
3. Data is saved locally on your device

### Option 2: Install as App (iOS)
1. Open Safari and go to the app URL
2. Tap the **Share** button
3. Select **"Add to Home Screen"**
4. Tap **"Add"**
5. Open from your home screen

### Option 3: Install as App (Android)
1. Open Chrome and go to the app URL
2. Tap the **Menu** button (3 dots)
3. Select **"Install app"**
4. Tap **"Install"**
5. Open from your home screen or app drawer

### Option 4: Run Locally
```bash
# Clone the repository
git clone https://github.com/merker454/Read-Quest.git
cd Read-Quest

# Open the app in your browser
open index.html
# or for Windows:
start index.html
```

## 📖 How to Use

### 1. Create a Reader Profile
- Click **"+ New"** to create a profile
- Enter reader's name
- Choose a reading level (Early Reader, Junior, Teen, or Adult)
- Pick a custom avatar (50+ emoji options)
- Click **"Create"**

### 2. Add Books
- Click the **Books** tab
- Click **"+ Add Book"**
- Select a book from the recommendations list
- Enter chapters (optional)
- Click **"Add Book"**

### 3. Track Reading Progress
- Find your book in the list
- Click **"Log Chapter"** to record each chapter read
- Repeat as you read
- Earn points automatically based on level

### 4. Complete Challenges
- View **Challenges** tab
- Complete weekly/monthly/streak goals
- Unlock rewards when challenges are met
- Enter custom rewards (e.g., "Ice cream party", "Movie night")

### 5. Take Quizzes
- Go to **Books** tab
- Click **"Take Quiz"** next to a completed book
- Answer questions generated by AI
- See your score and explanations
- Learn more about what you read

### 6. View Progress
- Check **Dashboard** for stats:
  - Total points earned
  - Books completed
  - Current reading streak
  - Level progression

## 💾 Data & Privacy

### How Your Data Works
- ✅ **All data is stored locally on your device** using browser storage
- ✅ **No accounts needed** - No email or password required
- ✅ **No data sent to servers** - 100% privacy
- ✅ **Free forever** - No ads, no tracking, no monetization
- ✅ **Portable** - Export your data anytime

### Data Backup
Since data is stored locally:
- 📱 Back up your device regularly
- 💾 Export your reading data periodically
- 🔄 Data persists across sessions until you clear browser storage

## 🐛 Known Issues & Limitations

### Limitations
- 🔸 Data stored locally only (no cloud backup)
- 🔸 No automatic cross-device sync
- 🔸 Quiz generation requires internet
- 🔸 Limited to 5 sample quizzes pre-built

### Workarounds
- Manually backup your browser storage regularly
- Export reading data and save it
- Install app on multiple devices separately
- Use offline mode without generating quizzes
